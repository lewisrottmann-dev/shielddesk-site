Security desk workflow

1. Review the request

Paste a suspicious message or URL before clicking, paying, sharing codes, or installing remote-access software.

2. Create a local case

Capture what happened, where it came from, priority, source, and next status without sending data to a hosted backend.

3. Export for support

Generate a user-controlled support bundle with cases and the latest message or link triage result.
