# Kairnex ShieldDesk Privacy Policy

Last updated: May 2, 2026

Kairnex ShieldDesk is a local-first Mac desktop app from Kairnex Solutions. The app is designed to help users review suspicious messages and links, track support cases, maintain a security checklist, and export support bundles when the user chooses to do so.

## Data Stored by the App

Kairnex ShieldDesk may store support cases, checklist status, settings, message triage results, URL triage results, and evidence file metadata locally on the user's Mac.

## Evidence Files

When a user selects files as case evidence, Kairnex ShieldDesk records file metadata such as file name, file size, file type, and selection time. This version does not upload or copy selected files to a remote service.

## Network Use

Kairnex ShieldDesk does not require a user account or backend service. When a user chooses to send a case to support, the app opens the user's default email client with a prepared message.

## Support Bundles

Users can export a JSON support bundle containing local case, checklist, setting, and triage data. The user controls where that file is saved and whether it is shared.

## Diagnostics

The diagnostics setting is user-controlled and may be included as a flag in exported support bundles.

## Data Sharing

Kairnex ShieldDesk does not sell user data. Data is shared only when the user chooses to export a support bundle or send information through their own email client.
